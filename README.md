# Resourcely. — Academic Resource Hub

> Elevating academic discourse, one document at a time.

Resourcely is a premium, open-access academic repository designed for university students. It provides a quiet, focused environment to share and discover course materials, research notes, and past papers. 

## 🌟 Key Features

- **Peer-Sourced Materials**: Syllabi, lecture notes, and study guides contributed directly by the student body.
- **Rigorous Organization**: Metadata-driven architecture ensures you find exactly what you need by discipline and semester.
- **Unrestricted Access**: No paywalls. No aggressive tracking. Just unhindered access to human knowledge.
- **Cinematic UI/UX**: Built with Framer Motion and modern Tailwind CSS for a sophisticated, luxury aesthetic.

## 🛠️ Technology Stack (MERN)

- **Frontend**: React 19, Vite, Tailwind CSS v4, Framer Motion, Lucide React
- **Backend**: Node.js, Express.js (Integration in progress)
- **Database**: MongoDB (Integration in progress)
- **Routing**: React Router DOM v7

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Clone the repository
2. Install frontend dependencies:
   ```bash
   cd client
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
